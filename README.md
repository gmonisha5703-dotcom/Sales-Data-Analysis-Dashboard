# Sales Data Analysis Dashboard

## Project Description
This project analyzes sales data using Python, Pandas, and Matplotlib to identify product-wise sales performance.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Power BI
- Excel

## Features
- Sales Data Analysis
- Total Sales Calculation
- Product-wise Sales Analysis
- Sales Visualization using Bar Charts

## How to Run
1. Install Python.
2. Install Pandas and Matplotlib.
3. Run sales_analysis.py.
4. View the sales results and chart.

## Project Objective
To analyze sales performance and understand product-wise revenue.
